# Git standards

- Conventional commits (`feat:`, `fix:`, `refactor:`, `docs:`, `chore:`); subject ≤ 72 chars, body says why.
- Branch per task: `feature/<short>`, `fix/<short>`.
- PRs are small and single-purpose; description states intent, approach, and any `ASSUMPTION:`s made.
- Agents: never force-push shared branches; never commit generated files unless the baseline says so.
