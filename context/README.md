# Context

Small, focused domain documents — the digestible alternative to a 4000-line README. Target: one file per domain, ~150 lines max, written for someone (human or agent) touching that domain *today*.

Each doc answers: what this domain does, its key entities and invariants, how it connects to neighbors, the traps. Use `_template.md`. When a doc grows past ~150 lines, split it.

Agents: read only the context files for the domains your task touches.
