# Self-evaluation

End every task with this scorecard. Score honestly — a 10 requires evidence; unverified claims cap at 7. Anything ≤ 7 gets one line on what would raise it.

```
Evaluate your work.
Architecture      n/10
Security          n/10
Testing           n/10
Maintainability   n/10
Performance       n/10
Documentation     n/10
Confidence        nn%   ← probability this is mergeable as-is
```

Below the scorecard list: assumptions made (`ASSUMPTION:` lines), anything skipped and why, and any baseline improvement this task suggests (see `docs/continuous-improvement.md`).
