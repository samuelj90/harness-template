# Task kickoff patterns

- Feature: `Use skills/add-feature.md for: <task>. Domains: <x, y>.`
- Bug: `Use skills/fix-bug.md. Report: <paste>.`
- Refactor: `Use skills/refactor.md targeting <smell> in <area>.`
- Review: `Use skills/review-pr.md on this diff.`
- Ship: `Run checklists/release.md against the current state.`
- Anything else: `Read AGENTS.md and pick the matching skill; state which you chose.`
